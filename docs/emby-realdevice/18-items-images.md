# #18 `GET /api/emby/Items/{ItemId}/Images/{type}[/{index}]`（条目图片）

> 索引：[emby-compat.md「十、真机对照记录」](../emby-compat.md)


**真机样本**（予初Emby 4.9.5.0 / nyamedia 4.8.0.62 / OkEmby / itsmygo；四台均已取到）

样本条目：予初Emby 电影 `864879`、nyamedia 电影 `232431`、OkEmby 电影 `47156`、itsmygo 现查的电影（标准 Guid）。**字节数只作参考**：这几台网络时通时断、传输会被截断（出现过 `0` 等假长度），故以「**完整下载 + 读真实像素**」为准，下表括号里标像素。

| 请求 | 含义 / 客户端用途 | 予初Emby | nyamedia | OkEmby | itsmygo |
|---|---|---|---|---|---|
| 有效 token + `Primary`（无 tag） | 列表 / 详情海报 | **200** `image/jpeg`（582×873） | **200** `image/jpeg`（1000×1426） | **200** `image/jpeg` | **200** `image/jpeg`（2000×3000） |
| **无 token** + `Primary` | 客户端取图不带凭证 | **200** 出图 | **200** 出图 | **200** 出图 | **401** `{"error":"unauthorized"}` |
| **无效 token** + `Primary` | 同上 | **200** 出图 | **200** 出图 | **200** 出图 | **401** 同 |
| 有效 token + `Backdrop` | 背景图 / 详情大图 | **404** 纯文本（该条目无背景图，非鉴权问题） | **200** `image/jpeg` | **200** `image/jpeg` | **200** `image/jpeg`（318829B） |
| 有效 token + **不存在的 ItemId** | 客户端缓存了已删条目 | **500** 纯文本（53B） | **500**（53B） | **500** 纯文本（53B） | **404** 纯文本 `404 page not found` |
| 有效 token + **伪造 tag** | `tag` 是否当凭证 | **200** 出图（`tag` 无影响） | **200** 出图 | **200** 出图 | **200** 出图（`tag` 无影响） |
| 有效 token + `Primary/index0` | 多张背景图逐张要 | **200** 出图 | **200** 出图 | **200** 出图 | **200** 出图 |
| 有效 token + `?maxWidth=300` | 客户端要缩略图 | **300×450（等比缩放）** | **300×428（等比缩放）** | **300×450（等比缩放）** | 2000×3000（**忽略**、回原图） |

**判读**：**"图片要不要 token" 上四台不一致** —— 予初Emby / nyamedia / OkEmby **不校验 token**（无 / 无效 token 照样 200 出图）；itsmygo **校验 token**（无 / 无效 → 401，且是 `{"error":"unauthorized"}` 的 **JSON**，非 Emby 惯例纯文本，因其是仿 Emby 服务）。四台对 **`tag` 都在"可选缓存键"语义**下（伪造 tag 不影响出图），**都不把 tag 当取图凭证**；`/index` 四台**均忽略**、照出图。**`maxWidth` 也不一致**：予初Emby / nyamedia / OkEmby **按宽等比缩放**（真 Emby 行为），itsmygo **忽略**、回原图。

**差异处理**

- 18-1 **鉴权口径 → 维持「豁免 AccessToken」，不复刻 itsmygo 的 401**：面板图片端点**豁免 AccessToken**（[ADR-0036](../adr/0036-image-endpoint-redirect.md)），与**予初Emby / nyamedia / OkEmby 一致**；itsmygo 要求 token **不一致**。但 ① 实测客户端取图**不带任何凭证**（见「五」那条：8 条里 3 条啥都不带），收紧成"必须 token"会**直接打不出图**；② 面板**没有片库索引**，图片位置只能编码进 URL、无从"按 Id 反查上游"。故**维持豁免**，itsmygo 的 401 **登记不复刻**。
- 18-2 **响应形状 → 302 不加 200 字节（既定设计）**：真机**直接回图片字节**（200 `image/jpeg`）；面板**302 到原图**、不代取字节（[ADR-0036](../adr/0036-image-endpoint-redirect.md) / [ADR-0006](../adr/0006-redirect-for-playback.md)）。**有意偏离**，客户端跟随 302 拿到同一张图。
- 18-3 **失败码 → 取 404，不复刻真机的 500**：不存在的 `ItemId`，予初Emby / nyamedia / OkEmby 都回 **500**、itsmygo 回 **404** —— **真机自身不一致**。面板对 `tag` 缺失 / 验签不过 → **404**（不 500，防枚举），与 itsmygo 同、与另三台不同。
- 18-4 **`tag` 语义 → 有意强化**：真机 `tag` 属**可选缓存键**（伪造也照出图）；面板把它当**唯一取图凭证**（`cpimg.<base64url(URL)>.<签名>`，认不出即 404）—— 因面板无片库索引、直链只存在于 tag 里。**有意偏离**。
- 18-5 **itsmygo 的 401 形状（JSON）→ 登记备查**：`{"error":"unauthorized"}`，非 Emby 纯文本惯例；面板既有 401 仍是纯文本 `Access token is invalid or expired.`，**不复刻**。
- 18-6 **`/index` → 一致 ✓**：四台均忽略 `index`（回原图）；面板同样忽略（302 原图）。客户端行为无差异。
- 18-7 **`maxWidth` → 有意偏离（面板不缩放）**：真机（予初Emby / nyamedia / OkEmby）按 `maxWidth` **等比缩放**后回图（真 Emby 行为；itsmygo 忽略）。面板**一律 302 到原图**、不代取字节，故 `maxWidth` **传不到源站、客户端拿到原图**（[ADR-0036](../adr/0036-image-endpoint-redirect.md) / [ADR-0006](../adr/0006-redirect-for-playback.md)）。面板无图片处理、也不代取流量，**不缩放有意为之**；客户端把大图缩到缩略尺寸显示，功能不受影响（仅多耗一点带宽）。**有意偏离**。

**面板特有行为（有意偏离，先不改）**：302 + 签名 tag 当凭证（真机 200 直出字节、tag 仅缓存键）；同一图片路径对客户端而言是"跟随 302 取到同一张图"，观感一致；`maxWidth` 不缩放（302 原图，见 18-7）。

**不能模拟**：真机图片来自它自己的片库 / 元数据；面板无片库索引，图片位置由上游（元数据插件）现给、编码进签名 tag。

**状态：18-1 维持豁免（登记 itsmygo 差异、不复刻）；18-2 / 18-4 / 18-7 有意偏离；18-3 取 404；18-5 登记备查；18-6 一致 ✓。** 四台样本均已取齐（**OkEmby 全量、nyamedia 的 `Backdrop` / 不存在 `ItemId` / `maxWidth` 已补齐**；这几台网络时通时断，靠多轮重试取得）。
