# ADR-0056 Emby 兼容层的范围界定：只照官方 API 的表面

- 状态：已采纳
- 相关：[0008](0008-no-fabricated-data.md)（不编数据）、[0007](0007-emby-dto-shape.md)（DTO 形状对齐真机）、[0048](0048-emby-userid-not-identity.md)（读取类只验 token）

## 背景

兼容层的目标之一是"新客户端开箱能动"。客户端是黑盒、更新频繁，追着客户端走不可行，只能照客户端都认的那套表面，把服务端这一侧做全、做一致。

但"做全"没有边界就会无限膨胀，还会把**官方服务器自身的能力**误当成面板的缺口。此前把"阶段 A"说成"拉全官方 API、逐条补缺口"，方向对、范围没界定。

界定范围的关键在坐标：本项目 Emby 层与官方 Emby 服务端**都是翻译层** —— 各自把自家的东西翻译成同一套 API 表面给客户端用。能对照的只有 **API 这层表面**（端点 / 参数 / DTO 字段 / 状态码 / 失败语义）；表面之下各自有什么，互不相干。因此对照物是 **Emby 官方 API 的端点清单**，而不是"面板能力 ↔ 官方服务端能力"。

## 决定

逐条端点问一句：**这条 API 背后的能力，是不是"面板的东西"？**

- 是 → **界内**：按官方形状作答。已有 → 已实现；没有 → 待补。
- 不是 → **界外**：不认领、不实现（落 501 或判定不实现）。

只有两态，不设"界内但口径不同"这类中间档。

两种"空"分开处理：

- 界内、没数据 → **如实回空**（[0008](0008-no-fabricated-data.md)）—— 认领了，只是没货。
- 界外 → **根本不认领** —— 不是本层的东西。

界内只界定"该管的范围"，**具体补哪条仍由部署者指定**（铁律，见 [emby-compat.md](../emby-compat.md)「一」）；界外一律不碰。

已定判定：

| 判定对象 | 归类 |
|---|---|
| 转码 | 界外 |
| 本地库扫描 | 界外 |
| 用户权限 / 家长控制 | 界外 |
| 条目「特别收录」（`SpecialFeatures` / `LocalTrailers` / `Intros`） | 界外 |
| 收藏（`Filters=IsFavorite`） | 界内，待补（现行如实回空） |
| `/Users/Public` | 界内，待补 |
| `POST /Sessions/Logout` | 界内，待补 |

## 理由

- **以静制动**：客户端只认那套统一表面。把方向从"追客户端"转为"照官方 API 表面把面板能给的填满、填一致"，才是"每来个新客户端都要适配一遍"这一处境的解法。
- **判据可自洽**：一句"是不是面板的东西"就能把范围钉死，既防清单无限膨胀，也防把服务器自身能力当缺口。
- **两态而非三态**：中间档会把界外能力（转码、本地库扫描）重新拉回"待补"，范围重新模糊。要保留的差异（如请求扇出放大，见 [emby-semantics.md](../emby-semantics.md)）不是"界内但口径不同"，而是界内某条支路的实现取舍。
- **与 0008 一致**：界内没数据回空是"如实"，界外不认领是"不在其位"，两回事，不能混。

## 备选

- **拿"面板能力 ↔ 官方服务端能力"当对照**：坐标错。两边都是翻译层，表面之下无可比性；照这个比会把官方服务器的本事（转码 / 本地库扫描 / 用户权限）全列成面板的缺口。没选。
- **三态（加"界内但口径不同 / 降级"一档）**：会把转码、本地库扫描这类界外能力重新收编成"界内待降级"，范围重新模糊。没选。
- **不界定范围，照官方 API 全量补**：清单无限膨胀，且大量条目本质是官方服务器自身能力，补不了也不该补。没选。

## 后果

- **界外**（不认领、落 501 或判定不实现）的典型：转码、本地库扫描、用户权限 / 家长控制，以及不在 Emby 核心协议里的第三方插件端点（如 `System/Ext/ServerDomains`，见 [emby-compat.md](../emby-compat.md)「七」）。这类不再列入"待补"。
- **条目「特别收录」端点判界外**（`SpecialFeatures` / `LocalTrailers` / `Intros`）：背后是**条目文件夹里的本地附加视频**（Emby 里每条花絮是一个可播文件），与本地库扫描同类 —— 面板没有本地文件、也没有"每条花絮是一个可播条目"的管道；且**片源插件只有正片、查不到花絮**，认领了也只能回空，客户端点「花絮」永远没内容，没意义。故**不认领**（维持 501），见 [emby-compat.md](../emby-compat.md)「七」。
- **界内待补**沿用 [develop.md](../develop.md)「未实现」一节的既有登记：收藏、`/Users/Public`、`POST /Sessions/Logout`、`GenreItems` 列表端点、用户级 `Similar`。补齐前，能回空的按 [0008](0008-no-fabricated-data.md) 如实回空。
- 收藏的判定随之翻：此前记在 [emby-compat.md](../emby-compat.md)「六」的"无视 —— 不补"改为**界内待补**；现行实现不变（仍如实回空），补齐前维持如实回空。
- 文档同步：[emby-compat.md](../emby-compat.md)「一」加范围指针、「六」的收藏条目改判；待补清单落在 [develop.md](../develop.md) 的「未实现」一节。
