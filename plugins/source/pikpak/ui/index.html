PikPak 磁力片源 · 设置

搜到磁力后，详情页给出的文件清单来自磁力站的种子（不提交离线下载、不占网盘空间）； 只有真正点播放时才把磁力提交到 PikPak，等云端下完再取回可直连的播放地址。 同一个资源第二次播放会直接命中保存目录里已有的那份，不会重复下载。

账号

令牌与密码都存在插件自己的数据目录里，不会写进日志、也不会回显到这一页。 已保存的令牌会一直用到过期；只有在令牌过期时才走「刷新令牌 → 账号密码」这条退路 —— 频繁登入登出会触发 PikPak 风控，所以别反复点「登录一下」。

磁力站与保存目录

面板一次调用最长 60 秒，等待秒数留出余量给「列目录 + 挑文件」；等不到就如实报「还没下完」，下次点开接着等。
