这一页是插件自己的设置：站点地址、封面地址与缓存都归它管，存在插件自己的数据目录里（面板不读也不写）。 要改面板那边的聚合口径（打分、超时、选哪些站点），去「聚合设置 → 模板」。

站点

影片页地址拼法：站点基地址 / 语言段 / 影片编号；封面：封面基地址 / 影片编号 / cover-t.jpg。

一键自检

发一发站内搜索，如实报通不通、多少毫秒、解析出几条；用的是上面那几个框里的当前值（不必先保存）。

插件自己的缓存

这里存的是这个插件自己从站点取回来的页面原文（搜索页与影片页），命中就不打站点、秒回。 它和面板侧那份「线路结果」缓存不是一回事：那份由面板按天管。
