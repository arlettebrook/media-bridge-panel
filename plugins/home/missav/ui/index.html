MissAV 首页 · 站点连接

这两个地址是会变的（镜像域名与封面站）：填错了整行都取不到内容。测试用的是输入框里当前的值，不必先保存。

行参数

每一行 = 客户端里的一个媒体库。榜单类各占一行；「无码 / 亚洲 / 质量」那几行的入口路径是个下拉框， 选中哪个分类，那个库就装哪个分类的内容。最后的「自定义入口」可以填站点里任意模块的路径。 路径里那段 /dm<数字> 前缀会变，站点改版时在这里改。

结果缓存

缓存是这个插件自己的（面板不碰）：每一行的条目列表按行声明的时长存在插件的数据目录里， 重启之后热门行还是热的。清空只影响取数，不影响上面的设置。

这一页管什么

站点基地址、封面基地址、每行的入口路径都归这个插件：面板不读也不写这份设置。 面板只按插件申报的行清单做出客户端的「媒体库」，再按行 id 让它取数（rows / run 两个动作）。 条目 Id 与图片地址的最终形态由面板统一规定，插件只提供自己的条目编号与图片地址。
